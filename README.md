# 📝 Quick Character Counter (ドラッグ文字数カウント)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
![Chrome Manifest V3](https://img.shields.io/badge/Chrome_Extension-Manifest_V3-green.svg)
![Aesthetics](https://img.shields.io/badge/Design-Glassmorphism-purple.svg)

Webページ上のテキストを**ドラッグ選択するだけ**で、その正確な文字数をリアルタイムで表示するブラウザ拡張機能です。
就職活動のエントリーシート（ES）作成、レポート執筆、文字数制限のある各種フォームへの入力時に、作業効率を圧倒的に高めます。

---

## ✨ 特徴

### 1. 🔍 ドラッグ選択で即座にカウント
テキストを選択すると、その選択範囲のすぐ上に美しいフローティングツールチップが出現し、文字数をリアルタイムで表示します。選択を解除するか他をクリックすると自然にフェードアウトします。

### 2. 🔲 空白・改行除外のスマートトグル
ツールチップ上にある専用トグルボタンをクリックするだけで、**「全体文字数」**と**「空白・改行を除外した文字数（ESでよく使われる基準）」**の表示を1タップで切り替え可能です。

### 3. ✍️ 下書き保存・リアルタイムカウンター付きポップアップ
ブラウザのツールバーからポップアップを開くと、その場で文章を入力して文字数を測定できる「簡易メモエリア」が使えます。

### 4. 🎨 洗練されたモダンなデザイン
グラスモフィズム（すりガラス効果）を取り入れた、視認性の高い美しいライト/ダークテーマ対応デザイン。ブラウザの雰囲気に合わせてシームレスに切り替わります。

### 5. 🔒 完全ローカル＆高いプライバシー保護
この拡張機能は、入力・選択されたテキストを外部サーバーに送信することは一切ありません。すべての処理がユーザーのブラウザ内で完結するため、機密性の高いESの下書きや個人情報を扱う際も完全に安全です。

## 🛠️ インストール方法（Chrome / Edge 等）

本拡張機能は、以下の手順で開発者モードとしてブラウザに読み込ませてすぐに使用できます。

1. **ファイルをダウンロード**
   - このリポジトリを手元に用意します。
2. **拡張機能管理ページを開く**
   - Google Chromeの場合：アドレスバーに `chrome://extensions/` と入力して開きます。
   - Microsoft Edgeの場合：アドレスバーに `edge://extensions/` と入力して開きます。
3. **デベロッパーモードをオンにする**
   - 画面右上にある「**デベロッパーモード**」のスイッチをオンにします。
4. **パッケージ化されていない拡張機能を読み込む**
   - 画面左上の「**パッケージ化されていない拡張機能を読み込む**」ボタンをクリックします。
5. **フォルダを選択する**
   - 本プロジェクトのフォルダ（`char-counter-extension` ディレクトリ）を選択して読み込みます。

これでインストールが完了します！

## 🚀 使い方

### 1. Webサイト上でドラッグする
任意のWebサイト（Google ドキュメント、企業のES提出画面、各種フォームなど）で、カウントしたい文章をドラッグ選択します。選択された文字数が浮かび上がります。

### 2. ポップアップで下書きを作る
ブラウザのツールバーにある拡張機能のアイコンをクリックします。
- **クイック入力**: メモ欄に入力・貼り付けした文章の「全体文字数」と「空白・除外文字数」がリアルタイムに表示されます。
- **テーマ設定**: ポップアップから、ツールチップの「ダークテーマ」「ライトテーマ」を切り替えることができます。
- **拡張機能のON/OFF**: 一時的にツールチップを非表示にしたい場合は、「拡張機能を有効にする」スイッチをオフにできます。
